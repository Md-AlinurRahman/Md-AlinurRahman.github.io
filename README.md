# Md. Alinur Rahman — GitHub Academic Portfolio

This package is ready to publish with GitHub Pages.

## Publish
1. Create a public GitHub repository. Recommended repository name: `alinurrahman.github.io` if that matches your GitHub username; otherwise use `academic-portfolio`.
2. Upload every file in this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose `main` and `/ (root)`, then **Save**.
6. GitHub will provide the public URL after deployment.
